# data/

## srd-spells.json

Generated by `npm run build:spells` (`scripts/build-srd-spells.ts`). Do not edit by hand; rerun the
script instead.

Each entry keeps only what the turn advisor needs: `name`, `level`, `castingTime`
(`action` / `bonus` / `reaction` / `other`), `range`, `area`, `save`, `attack`, `damage` and
`concentration`. Spells that aren't in this table are marked **unknown** on the review screen.
